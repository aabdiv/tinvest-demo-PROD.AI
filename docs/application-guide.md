# Профиль агента — MVP для Т-Инвестиции Premarket

Развёртывание демо на VPS Timeweb Cloud: [docs/deploy-demo.md](deploy-demo.md).

Человек своими словами рассказывает, чего хочет от денег. ИИ разбирает текст на отдельные пожелания,
паутина из пяти осей показывает форму портфеля, агент подбирает реальные бумаги Мосбиржи, пишет мандат
и предлагает сделки, которые можно оценить по одной картинке.

## Быстрый старт (5 минут)

Нужен Python 3.11+.

```bash
cd tinvest-mvp
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите OPENROUTER_API_KEY
python scripts/build_universe.py   # 2–5 минут: бумаги с Мосбиржи → data/universe.json
uvicorn backend.main:app --reload
```

Откройте http://localhost:8000.

## Аккаунт и несколько портфелей

Личный кабинет: **http://localhost:8000/account**. Внизу обоих исходных интерфейсов
добавлена вкладка «Аккаунт». В кабинете есть два явно обозначенных учебных примера:
«Нефтегаз и дивиденды» и «Смелая идея из видео».

Начало создания портфеля: **«Своя стратегия»** или **«Чужая идея»**. Во втором случае
источником может быть видео, статья или текст. Доступная статья читается по ссылке;
видео в продуктовом сценарии добавляется по ссылке или через выбор файла.

В существующем портфеле есть действие **«Добавить идею»**. Оно открывает его же чат
в режиме «Чужая идея», с выбором формата материала. Разбор сопоставляет материал
с текущим составом, историей, горизонтом и ограничениями. Новые цели автора не
становятся целями пользователя автоматически. Источник сохраняется в разделе
«Добавленные идеи», связанном с перепиской и предложенным планом.

Для демо-сценария новая тематическая идея получает лимит 10% плана. Оптимизатор
может подобрать меньшую долю или отклонить добавление из-за ограничений.
До подтверждения исходный профиль и позиции сохраняются; применение сценария
изменяет только план. Ребалансировка подтверждается отдельно.

## Агентное управление и идеи сообщества

В портфеле доступен выбор управления: **самостоятельно** или **поручить агенту**.
Во втором случае создаётся отдельный счёт с выделенной суммой, собственными позициями
и журналом решений. Исходный ручной состав сохраняется. Агент действует по подтверждённому
поручению; изменения профиля требуют отдельного обновления поручения. Управление можно
поставить на паузу, возобновить или вернуть владельцу, сохранив счёт и историю.

Новая вкладка **«Идеи»** открывает `/community`: каталог портфелей сообщества.
Можно искать идеи, фильтровать риск, изучать профиль, состав и ограничения;
взять портфель за основу или добавить его идею к существующему. Режим управления
своим портфелем выбирается отдельно. Примеры каталога — сценарии прототипа;
графики рассчитываются на загруженной истории, не являются статистикой живой торговли.

Кнопка «Поделиться стратегией» публикует в локальном каталоге явно выбранный снимок
стратегии. Переписка, исходные материалы, номера счетов и суммы не копируются в публикацию.
Пользователь задаёт публичные название и описание.

Проверки новых границ:

```bash
python tests/management_checks.py
```

Техническое устройство сценариев и границы прототипа описаны в
[docs/prototype-interfaces.md](prototype-interfaces.md).

- Каждый портфель хранит свой профиль, пятиугольник целей, красные линии, исходную идею,
  историю редактирования в чате и отдельный аналитический диалог.
- Карточка открывает `/v2?portfolio=<id>`: исходный редактор предпочтений, ниже — текущие
  виртуальные позиции и отдельная вкладка подобранного плана, распределение по отраслям.
- Можно создать портфель из собственных пожеланий или текста/расшифровки видео.
  Ссылка на TikTok или имя выбранного видео сохраняется как источник.
- В боковой чат можно отправить вопрос, текст новости, файл `.txt`/`.md` или публичную
  ссылку на статью. Доступные HTML-страницы читаются с ограничением размера и таймаутом;
  если сайт блокирует чтение, требуется вставить текст. Содержимое источника не является
  подтверждением достоверности события.
- Агент получает профиль, текущие позиции, исходную идею и историю разговора именно
  этого портфеля. При подключённом `OPENROUTER_API_KEY` используется языковая модель;
  без ключа работает явно обозначенный демо-разбор по правилам.
- Для обсуждения снижения концентрации рассчитывается сценарий «сейчас / предлагается»
  с пятиугольниками, долями отраслей и списком возможных виртуальных сделок. Расчёт
  проходит исходные ограничения, включая ранее установленные более строгие лимиты.
  Двухэтапное подтверждение меняет **план**, а не текущие позиции; виртуальная
  ребалансировка подтверждается отдельно через существующий интерфейс агента.

Состояние сохраняется автоматически в SQLite: `data/account.sqlite3` (не попадает в Git).
Можно задать другой путь переменной `ACCOUNT_DB_PATH`. При переносе своих портфелей
нужно отдельно скопировать этот файл. Изменения в другой вкладке проверяются по версии,
чтобы не перезаписать более свежие данные.

Это локальный кабинет одного пользователя: регистрации, разделения пользователей,
подключения брокера и реальных сделок нет. Не используйте его как публичный
многопользовательский сервис без добавления авторизации.

Проверка кабинета:

```bash
python tests/make_fake_universe.py
python tests/account_checks.py
```

**Без ключа** приложение работает в тестовом режиме: вместо LLM работают простые правила, и интерфейс можно прокликать сразу.
Сборщик без ключа тоже работает: отрасли берутся из ручной разметки крупных тикеров, а описаний бумаг не будет.

**Без доступа к Мосбирже** можно запустить на синтетических бумагах (только для проверки интерфейса):

```bash
python tests/make_fake_universe.py
UNIVERSE_PATH=tests/universe.fake.json uvicorn backend.main:app
```

## Ключ и модели

1. Зарегистрируйтесь на https://openrouter.ai, пополните баланс (для демо хватит $5) и создайте ключ.
2. В `.env` две ступени моделей:
   - `FAST_MODEL` — всё, что происходит, пока человек на экране: разбор пожеланий, поиск по теме, мандат, объяснения.
     По умолчанию `qwen/qwen3.8-27b`: быстрая, хорошо понимает русский, умеет structured outputs. Это модель того же
     семейства и размера, что T-Pro 2.0 Т-Банка (она собрана на Qwen3-32B), поэтому в продакшене её можно заменить на
     модель банка без изменений в коде.
   - `SMART_MODEL` — разметка карточек бумаг при сборке базы. Скорость не важна, по умолчанию `moonshotai/kimi-k2.6`.
3. Альтернативы для быстрой ступени: `openai/gpt-oss-120b` (дешевле и быстрее, но русский слабее, перед ответом
   рассуждает) и `google/gemini-3.6-flash` (надёжная, но дороже и медленнее по генерации).
4. Сравнить модели на своих фразах: `python tests/compare_models.py qwen/qwen3.8-27b openai/gpt-oss-120b`.
   Скрипт покажет время ответа и то, что каждая модель поняла.

Каждый вызов модели виден внизу экрана: что делали, какая модель, сколько секунд. Так удобно показывать жюри,
что интерфейс отзывчивый за счёт каскада, а не одной большой модели.

Ориентир по стоимости: один разбор пожеланий — доли цента, вся демо-сессия — меньше доллара.

## Что можно прокликать

1. **Слова → пожелания.** Напишите, чего хотите (или нажмите пример). Агент покажет чипы «что понял»; любой можно
   отменить крестиком и вернуть стрелкой. Можно дописывать комментарии по ходу, они добавляются к профилю.
2. **Противоречия.** Если пожелания спорят (дивиденды против ставки на IT), появится вопрос с двумя кнопками.
3. **Паутина.** Жёлтый контур — цель, заливка — что реально получилось из бумаг. Тяните точки: ось закрепляется,
   портфель пересобирается за доли секунды без LLM. Нажмите на подпись оси, чтобы открепить её.
4. **Параметры** — сумма и горизонт.
5. **Красные линии.** Появляются из слов («нефть не хочу») или добавляются текстом («не больше 10% в банках»).
   Агент технически не может их нарушить: фильтр и ограничения работают без LLM.
6. **Бумаги.** Список с наложением вашей фигуры и фигуры бумаги и процентом совпадения. Вкладки «В портфеле»,
   «Рассматривал», «Исключено». По клику на бумагу видно крупное наложение и объяснение агента; бумагу можно исключить.
   «Найти по смыслу» — агент-поисковик подбирает бумаги под тему.
7. **Мандат** — 2–3 предложения, которые обновляются после каждого изменения.
8. **История за 3 года** — как вёл бы себя такой портфель: доходность в год, худшая просадка в рублях,
   дивиденды и купоны. Это история, а не прогноз.
9. **Агент.** Выберите режим: «спрашивает о каждой сделке» или «сам в рамках мандата». «Доверить портфель агенту» —
   первая покупка с подтверждением на паутине. «Прожить квартал рынка» — портфель сдвигается на реальных
   доходностях одного из последних кварталов, и агент предлагает ребалансировку: мандат пунктиром, «сейчас» белым,
   «после сделок» жёлтым. В автономном режиме агент проводит сделки сам, если они не нарушают красные линии.
   Сделки виртуальные: реальный счёт не используется.

## Как устроено

```
frontend/            одна страница на чистом JS, без сборки
backend/
  main.py            API (FastAPI), каждый запрос несёт состояние профиля целиком
  schemas.py         состояние профиля — единственный источник правды
  profile.py         свёртка состояния: цель по осям, веса, красные линии, темы
  ai.py              все промпты и JSON-схемы, плюс тестовый режим на правилах
  llm.py             вызовы OpenRouter со structured outputs и запасными режимами
  optimizer.py       подбор бумаг и долей без LLM (SciPy, SLSQP), история за 3 года
  agent.py           исполнение, симуляция квартала, предложение сделок, проверка красных линий
scripts/
  build_universe.py  сборка базы бумаг из ISS Мосбиржи и разметка карточек LLM
  sectors.py         ручная разметка отраслей крупных тикеров
tests/               проверки без сети и синтетическая база
```

**Путь запроса:** текст → `interpret` (быстрая модель, ответ строго по JSON-схеме) → пожелания в состоянии →
`recompute` (поиск по темам быстрой моделью, если есть новые темы; дальше только математика) → `mandate` (быстрая
модель, с задержкой после последней правки). Перетаскивание паутины вызывает только `recompute`, без LLM.

**Как считаются оси бумаг (MVP):**
- Рост — среднегодовой рост цены за 3 года;
- Тренд — динамика за 3 и 6 месяцев;
- Дивиденды — дивиденды за 12 месяцев к цене, для ОФЗ — доходность к погашению;
- Устойчивость — низкая волатильность недельных доходностей;
- Качество — размер компании и ликвидность (для ОФЗ максимум).

Каждая ось — место бумаги среди всех бумаг базы по шкале 0–10. Устойчивость портфеля считается не средней по
бумагам, а из волатильности самого портфеля, то есть с учётом диверсификации.

## Известные ограничения MVP

- «Рост» и «Тренд» опираются на прошлую динамику цены, а не на прогнозы аналитиков.
- «Качество» в MVP — это размер и ликвидность, а не анализ отчётности.
- В доходность акций дивиденды добавлены равномерно по неделям, в ОФЗ — купонная доходность; это приближение.
- Отрасли некрупных тикеров размечает LLM и может ошибиться. Ручную разметку можно поправить в `scripts/sectors.py`.
- Голосового ввода пока нет.
