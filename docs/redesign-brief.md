# Версия 2: визуальный редизайн в стиле Т-Банка

Статус: дизайн-система подтверждена пользователем; визуальный слой V2 реализован.
Рабочая копия: `/workspace/tinvest-redesign-v2`, ветка `design/t-bank-v2`.
Замороженная копия версии 1: `/workspace/tinvest-version1`.
Исходное приложение: `/workspace/tinvest-PRODAI`.
Архив, контрольные суммы и версии зависимостей: `/workspace/tinvest-versions`.

## Сохраняемые страницы и сценарии

| Страница | Состав и поведение |
| --- | --- |
| `/` — главный подробный экран | Три колонки: ввод пожеланий, параметры и красные линии; пятиугольник целей, мандат, исторические показатели и действия агента; список и подробности бумаг. Тематический поиск, вкладки, отмена, сброс и подтверждение сделок сохраняются. |
| `/v2` — пошаговый интерфейс | Три шага: пожелания, бумаги, итог. Разговор, перетаскивание точек, закрепление осей, разрешение противоречий, поиск и исключение бумаг, итоговые показатели, выбор самостоятельности агента. |
| `/account` — личный кабинет | Обзор, карточки портфелей, режим управления в карточке, создание и редактирование. В создании: своя стратегия / чужая идея; видео / статья / текст, ссылка и загрузка видео, сумма и горизонт. |
| `/v2?portfolio=<id>` — сохранённый портфель | Заголовок и действия; управление человеком или агентом; отдельный счёт, поручение, пауза и журнал; предпочтения, пятиугольник и ограничения; текущие позиции и подобранный план; отрасли, добавленные идеи, исходный источник, личный чат и публикация. |
| `/community` — идеи сообщества | Каталоги «Портфели» и «Агенты», поиск и фильтры риска, карточки авторов и стратегий, профиль и состав, взятие за основу, добавление к существующему портфелю, открытие счёта с агентом. |

Общая навигация: «Портфель / Идеи / Аккаунт». Тексты, названия разделов, порядок
блоков, адреса страниц, формы, поля, условия отображения и обработчики действий
сохраняются. Декоративные эмодзи заменяются линейными SVG с тем же смыслом.

Отдельно сохраняются состояния: загрузка, пустой результат, ошибка, выключенный
контроль, несохранённые изменения, ожидающий подтверждения план, активный агент,
пауза, изменившееся поручение, навигация с клавиатуры и мобильная адаптация.

## Что обнаружено в текущем визуальном слое

- Почти все поверхности тёмные; фиолетовый широко используется рядом с жёлтым.
- В CSS семь градиентов, три объявления `backdrop-filter` и одно правило тени.
- Основной текст в ряде карточек и подписей уменьшен до 7–12 px.
- Заголовки преимущественно имеют веса 500–700; на страницах нет единой шкалы размеров.
- Карточки, формы и отступы оформляются несколькими пересекающимися стилями.
- Есть декоративные эмодзи закрепления осей и блокировки бумаг.
- Цвета SVG и диаграмм частично заданы в шаблонах JavaScript. Их нужно перенести
  на общие визуальные токены, сохраняя расчёты и действия.

## Предлагаемая дизайн-система

Направление: белая основа, графитовый текст и выделенные тёмные блоки, крупные
жёлтые действия. Плотность интерфейса снижается за счёт отступов и читаемого шрифта.

| Назначение | Значение |
| --- | --- |
| Главный акцент | `#FFDD2D` |
| Основной текст / тёмные панели | `#1C1C1C` |
| Второй графитовый тон | `#333333` |
| Фон | `#FFFFFF` |
| Поверхность карточек | `#F5F5F5` |
| Второстепенный текст | `#666666` |
| Разделители и границы | `#E5E5E5` |
| Ошибки и красные линии | `#D92D20`, только по смыслу |
| Успешное состояние | `#16834A`, только по смыслу |

Шрифт — Manrope с кириллицей: 800 для главных заголовков, 700 для подзаголовков
и кнопок, 500 для основного текста. Заголовок страницы 64 px, допустимый диапазон
48–72 px; разделы 32–40 px; карточки 22–26 px; основной текст 16–18 px;
подписи от 13 px. На мобильном заголовки 32–40 px. Трекинг крупных заголовков
около −0.04em, межстрочный интервал 1.05–1.15; у текста 1.5–1.65.

Сетка: контент до 1280 px, боковые поля 48 px на широком экране и 20–24 px
на мобильном. Шкала отступов 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 px.
Между разделами 64–96 px на широком экране, 32–48 px на мобильном.

Карточки — скругление 24 px, формы и поля — 16 px. Первичная кнопка — жёлтая,
чёрный текст, высота 56 px, скругление pill. Вторичная — белая с графитовым
контуром. Компактные действия от 44 px. Hover 150–200 ms: фон, граница,
небольшое смещение карточки. Явная обводка фокуса, поддержка reduced motion.

Нижняя навигация остаётся на месте; выбранный раздел выделяется жёлтой плашкой.
Иконки — единый линейный SVG-набор. Пятиугольник сохраняет оси и перетаскивание;
текущий и предлагаемый состав различаются графитовым/жёлтым цветом, заливкой
и типом линии. Подписи и значения остаются читаемыми без опоры только на цвет.

Не используются градиенты, размытие стекла, неоновые тени, стоковые иллюстрации
и декоративные эмодзи. Существующая сетка карточек каталога сохраняется;
новые маркетинговые блоки не добавляются.

## Выполненный порядок работ

1. Полный визуальный слой главной `/`: типографика, фон, карточки, формы,
   пятиугольник, таблицы, навигация и диалоги; затем скриншоты desktop/mobile.
2. Пошаговый и сохранённый портфели, кабинет, каталог сообщества и их диалоги.
3. Сквозная проверка исходных действий и сравнение с версией 1.
4. Проверка CSS, SVG и шаблонов на градиенты, фиолетовые/синие акценты,
   размытие, декоративные эмодзи и случайные изменения текстов.

Технологии остаются прежними: HTML, CSS и существующий JavaScript. Без React,
Tailwind и изменений серверной бизнес-логики. Все работы по редизайну выполняются
только в копии версии 2 после согласования этой системы. Результат и проверки — в `redesign-result.md`.
