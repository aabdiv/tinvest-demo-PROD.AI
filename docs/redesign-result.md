# Редизайн V2

Редизайн выполнен в отдельной копии `/workspace/tinvest-redesign-v2`, ветка
`design/t-bank-v2`. Исходный проект и `/workspace/tinvest-version1` сохранены.

## Оформление

- Белая основа, жёлтый `#FFDD2D`, графит `#1C1C1C` / `#333333`.
- Manrope с кириллицей, локальные файлы шрифта и лицензия OFL в `frontend/fonts/`.
- Общие токены в `frontend/design-system.css`, единые формы и кнопки, плоские карточки.
- Крупные заголовки, читаемые подписи, отступы, адаптивные сетки и линейные SVG.
- Перекрашены все пять экранов, аналитический чат, сценарии, управление агентом,
  таблицы позиций, публикация и диалоги создания и выбора стратегии.
- Градиенты, размытие, тени, фиолетовые/синие акценты и декоративные эмодзи удалены.

Первоначальный редизайн сохранил маршруты, блоки и поведение. Последующие
изменения интерфейса по разметке пользователя перечислены ниже. Серверный код V2
совпадает с V1.

## Проверки

- `tests/account_checks.py`: 13 тестов пройдены.
- `tests/management_checks.py`: 9 тестов пройдены.
- Chromium: создание портфеля из видео, ссылка и выбор файла, добавление идеи к
  существующему портфелю, независимый счёт агента, журнал, пауза/возобновление,
  возврат к ручному управлению, повторное использование счёта и публикация.
- Chromium: отправка пожеланий, перетаскивание и открепление осей в обоих редакторах,
  переходы между шагами, подробности и исключение бумаги, подтверждение сделок.
- Chromium: сохранение предпочтений и чата после перезагрузки, переименование,
  анализ новости, сравнение до/после и подтверждение применения плана.
- Адаптивные страницы проверены на 320, 390, 768, 1024 и 1440 px.
  Таблица позиций и строка подсказок сохраняют внутреннюю горизонтальную прокрутку.
- При первоначальном редизайне проверено сохранение исходных HTML-текстов;
  декоративные символы заменены SVG.
- Для исходного проекта и замороженной V1 совпадают все 54 контрольные суммы;
  база V1 совпадает с исходной. Все файлы `backend/` V2 совпадают с V1.

Браузерные сценарии выполнялись на отдельной тестовой базе в `/tmp`, не на базе
демонстрационных портфелей. Проверки API используют свои временные базы.

## Просмотр

Скриншоты: `/workspace/tinvest-versions/v2-previews/`.
Основные файлы: `account-review.png`, `community-review.png`, `agents.png`,
`overview.png`, `wizard.png`, `portfolio-management.png`, `portfolio-editor.png`,
`chat.png`, `create-video.png`. Мобильные экраны — `*-mobile.png`.

После установки зависимостей по основному README локальный запуск из каталога V2:

```bash
MOCK_LLM=1 python -m uvicorn backend.main:app --reload --port 8102
```

Страницы: `/`, `/account`, `/community`, `/v2`, `/v2?portfolio=example-oil`.
Настройки модели и данные остаются теми же, что в исходном проекте.

## Правки по отмеченным скриншотам

- Из аккаунта удалены счётчик обсуждений и блок о памяти агента.
  Два оставшихся показателя и карточки занимают всю ширину коллекции.
- В подробном редакторе удалены плашки режима модели и базы бумаг и переход
  «Пошаговый вид»; в пошаговом редакторе — «Подробный вид».
- Из подписи первого шага убрано «в любом порядке».
- В сообществе остался каталог портфелей: без вкладки, карточек и описания выбора
  агентов. Прежняя ссылка на карточку агента не открывает её в этом интерфейсе.
- Публикация стратегии создаёт карточку портфеля, доступную в этом каталоге,
  в том числе для портфеля, которым управляет агент.

Проверено в Chromium: загрузка аккаунта и обоих редакторов без удалённых элементов,
формы создания/редактирования, поиск и фильтры сообщества, копирование портфеля,
публикация из управляемого портфеля и отсутствие карточки агента по старой ссылке.
Ширины 320 / 390 / 768 / 1024 / 1440 px проходят без переполнения страницы и ошибок
JavaScript. Тестовые изменения выполнялись в отдельной базе `/tmp`.

Обновлённые скриншоты: `/workspace/tinvest-versions/v2-previews/revision-2/`.
